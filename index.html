Technical specs

Designed around the nRF52840

E73-2G4M08S1C

Pre-certified nRF52840 module with integrated PCB antenna, 32 MHz crystal, and DC-DC inductors. No RF design needed.

LP5024 LED Driver

24-channel constant-current sink over I²C. Drives 20 orange LEDs at ~1 mA each through translucent HEX keycaps.

3500 mAh LiPo

Single cell with BL8573 charger (1.47 A via USB-C), DW01A protection, and MAX17048 fuel gauge for accurate SoC reporting.

ZMK Firmware

Flexible keymaps, deep-sleep power management, and drag-and-drop USB updates via UF2 bootloader.

5×4 Key Matrix

Row-to-column scan with anti-ghosting diodes on every switch. 19 functional keys plus a dedicated hardware power switch.

USB-C + ESD

USBLC6-2SC6 ESD protection on D+/D−. Polyfuse on VBUS. Charging and data over a single port.

Architecture

Two-board design connected by FPC

Power flow

Module board

Carries the E73 nRF52840 module, LP5024 LED driver, MAX17048 fuel gauge, BL8573 charger, DW01A battery protection, the power-switch latch circuit, USB-C connector, and all passives.

Matrix board

Houses the 20 key switches (snap-in via hotswap sockets), per-key diodes (JLCPCB assembled), and 20 hand-soldered per-key LEDs. Connected to the module board by flat flexible cable.

Power latch

Long-press on S20 triggers an RC-timed Schmitt trigger (SN74LVC1G17) into a D-flip-flop (SN74LVC1G74) that toggles a P-MOS gate. The MCU also senses the press via PWR_BTN_PRESS for software functions while powered on.

Always-on vs. switched

MAX17048 taps BAT+ directly, so fuel-gauge readings stay live even when the board is "off." The MCU, LED driver, and LEDs only receive power once Q1 switches BAT+ onto the PWR rail.
